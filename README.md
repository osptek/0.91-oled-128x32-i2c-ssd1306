# 0.91 寸 128×32 OLED I2C 模组（SSD1306）资料与示例

**English：** [`README_EN.md`](README_EN.md)

---

> 本仓库提供该模组的 **ESP-IDF 示例工程**。数据手册与规格书待后续补充至 `docs/`。

## 产品概要

| 项目 | 说明 |
|:--|:--|
| 模组规格 | 0.91 英寸 **OLED**（单色），分辨率 **128×32** |
| 接口 | **I2C** |
| 驱动芯片 | **SSD1306** |
| 规格标识 | 产品资料中常用 **`0.91-oled-128x32-i2c-ssd1306`** 表示本规格 |
| 相近规格 | **0.96″ 128×64 OLED I2C** 见 **`0.96-oled-128x64-i2c-ssd1315`**（SSD1315），尺寸与驱动不同、独立维护 |
